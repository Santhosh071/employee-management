# Employee Management System

A console-based employee management app built with Core Java. You can add, view, search, update, and delete employee records — all managed in memory using a HashMap.

**Tech used:** Java · OOP · Collections (HashMap, ArrayList)

---

## Features

- ➕ Add employee with ID, name, age, department, address, and contact
- 📋 View all employee records
- 🔍 Search by name or ID
- ✏️ Update employee details (skip fields to keep current value)
- 🗑️ Delete by ID or name
- ✅ Input validation (age range, 10-digit contact, unique ID)
